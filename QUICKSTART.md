# Quick Start Guide

## Docker Method (Easiest)

1. Install Docker Desktop from https://www.docker.com/products/docker-desktop/
2. Open terminal in the project folder
3. Run: `docker-compose up --build`
4. Open browser to http://localhost:8080
5. Start adding date ideas!

To stop: Press `Ctrl+C` or run `docker-compose down`

## Local Development Method

1. Install Node.js from https://nodejs.org/
2. Open terminal in the project folder
3. Run: `npm run install:all`
4. Start backend: `npm run dev:backend` (in one terminal)
5. Start frontend: `npm run dev:frontend` (in another terminal)
6. Open browser to http://localhost:5173

## First Steps

1. Switch between "User 1" and "User 2" in the header dropdown
2. Click "Add Date" to create your first date idea
3. Go to "Randomizer" tab and select categories
4. Click "Spin the Wheel!" for a random date
5. Accept or reroll!
